下載修補工具 原始碼

使用方式

  1. 到下載頁取得 GalleryPckPatcher.exe 與 gallery-zh-payload.zip，放在同一個資料夾。
  2. 執行 GalleryPckPatcher.exe。
  3. 選擇遊戲資料夾裡的 galleyhouse.pck。替換包會自動填入。
  4. 按「開始」並確認。完成後啟動遊戲，檢查文字與圖片。

工具做了什麼

備份
在原檔旁建立 galleyhouse.pck.日期時間.bak，並驗證內容相同。
解包與替換
解開 .pck，把替換包的檔案放進去，同名檔案會被取代。
重新打包與驗證
打包成新 .pck，確認每個檔案都正確，才取代原檔，最後刪除暫存的解包資料夾。

任何一步失敗，原本的 galleyhouse.pck 都不會被改動。

還原

刪除修改過的 galleyhouse.pck，再把備份檔改名回 galleyhouse.pck。

注意

  • 這是非官方的民間修補。遊戲更新後 .pck 會被覆蓋，需要重新執行一次。
  • exe 沒有數位簽章，Windows 可能顯示「未知的發行者」警告。
